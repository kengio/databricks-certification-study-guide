# Mock Exam 1 — Databricks ML Associate

Simulate the real exam under timed conditions before your test date.

## Exam Instructions

| Detail | Value |
| ------ | ----- |
| Total Questions | 48 (the real exam has 48 scored questions plus up to 10 unscored items) |
| Time Limit | 90 minutes |
| Target Score | 70% (34 or more correct) — a self-assessment target; Databricks does not publish a passing score |
| Format | Single-answer multiple choice (the real exam also includes multiple-selection questions) |

## Section Distribution

## How to Take This Exam

1. Set a 90-minute timer before opening [questions.md](./questions.md)
2. Answer all questions without referring to notes or documentation
3. Expand the `[!success]- Answer` callout only after committing to an answer
4. Score yourself per section to identify weak areas
5. Review [exam-tips.md](../exam-tips.md) if scoring below 70%

## Scoring Guide

| Score | Result | Action |
| ----- | ------ | ------ |
| 39–48 (80–100%) | Excellent — ready to sit the exam | Schedule your exam |
| 34–38 (70–79%) | Likely passing — review weak areas | Review missed topics, attempt Mock Exam 2 |
| 29–33 (60–69%) | Close — focused study needed | Study weak sections, retry in 1 week |
| Below 29 (<60%) | Not ready — comprehensive review needed | Review all study material before retrying |
