# Practice Questions

Scenario-based practice questions organized by the 9 sections of the Oct 9, 2026 exam guide. 82 of the 155 questions are marked *(2026 blueprint)* — they target skills that are new or reworded in that guide (AUTO CDC, VARIANT, `ai_query`, ABAC, OpenSharing, Clean Rooms, Lakeflow Connect, metric views, `CLUSTER BY AUTO`, alerts, and more).

> [!note]
> The question files were renumbered when they were regrouped into the 9 sections, so progress saved in the practice quiz under the old 8-file layout does not carry over.

## Scoring Guide

| Score | Assessment |
| :--- | :--- |
| ≥ 80 % correct | Excellent — ready for the exam |
| 70–79 % | Good — review weak sections |
| 60–69 % | Fair — more study needed |
| < 60 % | Work through the topic folders again |

Databricks does not publish a numeric passing score for the Oct 9, 2026 exam guide; the bands above are study guidance only.
