# Mock Exam 1 — Databricks Data Engineer Associate

Simulate the real exam under timed conditions before your test date.

## Exam Instructions

| Detail | Value |
| ------ | ----- |
| Total Questions | 45 |
| Time Limit | 90 minutes |
| Target Score | 70 %+ (32 or more correct). Databricks doesn't publish a passing score |
| Format | Multiple choice, single correct answer |

## Domain Distribution

Questions are grouped by the 7 domains of the August 2026 exam guide. Since the October 2026 rebalance, each domain gets its share of the 45 questions at the official weight, rounded to whole questions. CI/CD and Troubleshooting both come to 4.5, so they are split 5 and 4.

| Domain | Official weight | Share of 45 at that weight | Questions in this mock |
| ------ | :---: | :---: | :---: |
| Databricks Intelligence Platform | 6 % | 2.7 | 3 |
| Data Ingestion and Loading | 21 % | 9.45 | 9 |
| Data Transformation and Modeling | 22 % | 9.9 | 10 |
| Working with Lakeflow Jobs | 16 % | 7.2 | 7 |
| Implementing CI/CD | 10 % | 4.5 | 5 |
| Troubleshooting, Monitoring, and Optimization | 10 % | 4.5 | 4 |
| Governance and Security | 15 % | 6.75 | 7 |
| **Total** | **100 %** | **45** | **45** |

## How to Take This Exam

1. Set a 90-minute timer before opening [questions.md](./questions.md)
2. Answer all questions without referring to notes or documentation
3. Expand the `[!success]- Answer` callout only after committing to an answer
4. Score yourself per domain to identify weak areas
5. Review [exam-tips.md](../exam-tips.md) if scoring below 70%

## Scoring Guide

| Score | Result | Action |
| ----- | ------ | ------ |
| 36–45 (80–100%) | Excellent — ready to sit the exam | Schedule your exam |
| 32–35 (71–79%) | Passing — review weak areas | Review missed topics, attempt Mock Exam 2 |
| 28–31 (62–70%) | Close — focused study needed | Study weak domains, retry in 1 week |
| Below 28 (<62%) | Not ready — comprehensive review needed | Review all study material before retrying |
